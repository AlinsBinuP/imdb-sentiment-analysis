> **Automatically classify IMDB movie reviews as positive or negative using Deep Learning (LSTM) and Natural Language Processing.**

---

## 📚 Overview

This project demonstrates how to use an LSTM-based neural network to perform sentiment analysis on the [IMDB Movie Reviews dataset](https://keras.io/api/datasets/imdb/).  
The model predicts whether a given movie review is **positive** or **negative**.

---

## 🚀 Features

- Loads and preprocesses the IMDB dataset
- Builds and trains an LSTM neural network
- Evaluates model accuracy
- Predicts sentiment for custom reviews

---

## 🖥️ Sample Results

| Review Example                                              | Predicted Sentiment |
|-------------------------------------------------------------|---------------------|
| This movie was fantastic and very exciting!                 | 0.761 (Positive)    |
| I did not like this movie. It was boring and too long.      | 0.103 (Negative)    |

**Test Accuracy:** `86.16%`

## 🧑‍💻 How to Run

1. **Clone this repository**
    ```
    git clone https://github.com/AlinsBinuP/imdb-sentiment-analysis/blob/main/imdb_sentiment_analysis.ipynb
    cd imdb-sentiment-analysis
    ```

2. **Open the notebook in Google Colab**  
   [Open in Colab](https://colab.research.google.com/drive/1uvbAgdMjxa8FnOOKaxkIPtee1hqb81-6?usp=sharing)

3. **Run all cells**  
   The notebook will:
   - Download the IMDB dataset
   - Preprocess the data
   - Build and train the LSTM model
   - Evaluate accuracy
   - Predict sentiment for your custom reviews
